# Vendored Neuracle NDF reader

These files come from the official
[`neuracle-ndffile-reader`](https://github.com/neuracle/neuracle-ndffile-reader)
repository, revision `6d86f3f3020424857ba9a29d54f6fa4877ce57f8`.

The only source changes are package-relative imports in `NDFSysMNE.py`,
`NDFSysParser.py`, and `ReadNDF.py`, so the reader can be imported as part of
MOABB. The upstream BSD 3-Clause license is reproduced in `LICENSE`.
